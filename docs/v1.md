# API

Write data
```
// Get or create semantics
val streamWriter = db.writer("streamUniqueName", dataType)

// Only supports current time
streamWriter.write(123)
```

Read data
```
val streamReader = db.reader("streamUniqueName")

// iterator returns data from oldest to newest
val iterator = streamReader.read(startTs, endTs)
```

# Implementation

Data is written to a write ahead log memtable and periodically flushed to sorted string tables.
Reads read the memtable and traverse SSTs from newest to oldest to find data.
No indexing, compression, etc is supported.

### Read

To get the SSTs with data in the requested range for the stream:

1. Read the header and footer from the newest SST
2. Verify the magic_number in the header and footer
3. Verify the SST version in the header
4. Check if the requested time is between footer min_timestamp, max_timestamp. If the max timestamp in the SST is below the min requested, stop all reads here. Only current timestamp writes are supported so older files cannot have data in the requested range.
5. Read the index and find all blocks that contain the requested stream.
6. Go to the next oldest SST and repeat until step 4 stop condition is hit

To read the actual data
1. Sort blocks from search phase above from oldest to newest
2. Read the entire block and verify the checksum.
3. Scan the block data. After the last requested stream data point is read then stop. Blocks are sorted by stream so no need to read more.
4. Go to the next stream.
